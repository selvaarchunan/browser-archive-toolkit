# Browser Archive Manager 📦

A lightweight, 100% client-side web utility to create and extract compressed archives directly in your browser. All processing is executed locally on your machine—no file uploads, no server bandwidth, and zero privacy concerns.

## ✨ Features

* **Multi-Format Extraction:** Unpack `.zip`, `.rar`, `.7z`, `.tar`, and `.tar.gz` files instantly.
* **Archive Creation:** Bundle files directly into archives without leaving the tab.
* **Complete Privacy:** Files never leave your local browser environment.
* **Zero Dependencies / Standalone:** Runs as a portable, single-file HTML web tool.
